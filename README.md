# Maria's birthday page

This folder is ready to publish as a small website. Upload the **contents of this folder** to your preferred hosting service (for example, Netlify Drop or GitHub Pages). Once it gives you a public `https://` address, create a QR code for that address and print/share it.

The webpage needs no installation or build step. Open `index.html` to preview it locally. The photo pop-ups will keep shuffling forever, and the “Tap for more magic” button makes an extra burst.

To customize the words, edit the message in `index.html`. To replace photos, put your own JPGs in `assets/` and update the `photos` list at the top of `script.js`.
